About Me

關於我

我是宋祐嘉（Ken），一位全端取向的軟體工程師。對寫程式的興趣始於大學，之後在台大資訊培訓班與緯育課程持續精進，從 C++ 資料結構與演算法，一路延伸到 Java 後端、Python 應用與前端框架。

我最大的特質是扎實的基本功與自我學習能力——能快速吸收新技術，並把它實際做出成果。在校期間透過畢業專題把技術落地，並以 IoT 智能門禁專題拿下 2022 高雄發明展金牌。

我的工作風格是以個人實力為核心、以 AI 為輔助：架構設計、邏輯拆解與程式品質由我親手掌握，AI（Claude 等）則用來加速設計、除錯與重構，把更多心力放在系統架構、資料處理與細節打磨。對我來說，AI 是放大生產力的工具而非取代判斷的依賴——能把問題拆解清楚、把程式寫穩，永遠是真正的關鍵。

AI Agent Engineering

AI Agent 工程

我想做的，是把腦中的設計實作成「會自主判斷、真的動手做事」的 Agent——整合 LLM、工具呼叫與企業系統，讓它能在辦公室、醫院、實驗室等真實場景中執行任務、跟人協作。

為什麼我適合這個職缺

Agent Harness · Guardrails

每天以 agent harness（Claude Code / Cowork）完成多步驟開發任務，實際體會 guardrails、安全邊界與失敗重試的設計取捨——不是只讀過概念，而是天天在用。

Tool Calling · MCP · A2A

在日常使用 agent 工具的過程中，熟悉 tool calling 與 MCP（Model Context Protocol）的運作方式——Agent 如何呼叫外部工具、拿到結果再決策，並持續深化 A2A 等 agent 間協作協定。

把人類流程 Agent 化

教學與後端開發的經驗，讓我習慣把一件事拆成清楚、可驗證的步驟——這正是把重複的人工流程交給 Agent 自主執行、再逐步驗證的基礎，也是職缺要的「將人類流程轉為與 Agent 協作」。

效能與 Token 用量優化

紮實的資料結構／演算法與 C++、多執行緒底子，讓我在意 context 設計、工具粒度與 token 成本——把「跑得動」做到「跑得省、跑得穩」。

整合進真實企業系統

Voyago 全端專案（Vue 3 + Spring Boot 3 + MySQL 8 + JWT，已上線）證明我能把服務接進真實後端與資料庫，這正是 Agent 落地企業原生系統所需的整合能力。

快速學習、驗證新技術

從 C++ 到 Java 後端、前端框架、再到 agent 工具，一路自學落地。面對新框架能快速吸收、動手驗證並做出可運作成果——這正是 Agent 領域每天需要的能力。

我正把重心轉進 AI Agent 領域，正處於快速成長的階段——每天以 agent 工具實作開發、熟悉 harness 與 guardrails，並以紮實的全端與 CS 基礎把服務接進真實系統，正持續補強 multi-agent 與 RAG 的實戰。給我一個把 Agent 做進真實場景的舞台，我會用最快的速度把它做出來。
